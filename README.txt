せどり仕入れアシスタント v2.1

重要：iPhoneのカメラを使うにはHTTPSで公開してください。
HTMLファイルを直接開く(file://)だけではカメラ機能は安定して動きません。

公開後はiPhoneのSafariでURLを開き、共有→ホーム画面に追加するとアプリのように使えます。

主な機能：
・HTTPSカメラによるJAN/バーコードスキャン
・バーコード写真からの読み取り
・店頭クイック利益判定
・商品写真
・仕入れ候補保存
・収支/設定
・CSV出力
・PWA対応

注意：バーコード読み取りライブラリはhtml5-qrcodeをCDNから読み込みます。初回起動時はインターネット接続が必要です。
